# Contributing to Persona Chat

Thanks for taking the time to improve Persona Chat. Code changes, tests, bug reports, and documentation fixes are all welcome.

## Before you start

- Search existing issues and pull requests before opening a new one.
- For major changes, please open an issue first so the maintainers can confirm scope and direction.
- Small fixes and documentation improvements can usually go straight to a pull request.

## Reporting bugs

Please include:

- what you expected to happen
- what actually happened
- clear reproduction steps
- environment details such as local vs Docker, OS, and AI provider
- logs, screenshots, or exported data samples when relevant

## Proposing features

Feature requests are most useful when they explain:

- the problem or use case
- the current limitation or workaround
- the proposed behavior
- any compatibility or scope concerns

## Submitting pull requests

1. Fork the repository and create a focused branch.
2. Keep the change set small and directly related to one problem.
3. Update documentation when behavior, setup, or user-visible output changes.
4. Run `pytest -q` and `pre-commit run --all-files` when practical.
5. Describe the motivation, key changes, and verification steps in the pull request.

## Documentation contributions

README improvements, onboarding notes, examples, and Korean/English clarity fixes are all valuable contributions.

## Security issues

For sensitive vulnerabilities, please do not open a public issue. Follow the private reporting guidance in [SECURITY.md](SECURITY.md).
